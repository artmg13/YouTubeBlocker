# Осознанный YouTube

Android-приложение для паузы перед просмотром: напишите развёрнутую причину, подтвердите её и продолжайте пользоваться YouTube. Подтверждённые причины сохраняются в журнале с датой и временем.

## Установка

1. Установите `artifacts/YouTubeBlocker-debug.apk` на Android 7.0 или новее.
2. Откройте «Осознанный YouTube» и нажмите «Включить защиту».
3. В системных настройках специальных возможностей выберите сервис «Осознанный YouTube» и включите его. На некоторых телефонах он находится в разделе установленных/загруженных приложений.
4. Вернитесь в приложение и убедитесь, что показан статус «Защита включена».
5. Откройте официальное приложение YouTube. Напишите причину и нажмите «Открыть YouTube» либо выберите «Передумал».

Если после установки APK Android блокирует подключение сервиса, откройте системные сведения о приложении → меню ⋮ → «Разрешить ограниченные настройки», если этот пункт доступен. Названия разделов зависят от устройства. На устройствах, ограничивающих фоновую работу, может потребоваться разрешить её в настройках батареи.

## Использование

- По умолчанию требуется 150 символов без пробелов и переносов строк. В настройках можно задать целое число от 50 до 5000.
- Смена роликов и разделов внутри YouTube не вызывает новый запрос. После перехода домой или в другое приложение причина потребуется заново. Блокировка экрана завершает сеанс.
- «Передумал» и системная кнопка «Назад» возвращают домой без записи. При новом входе поле пустое. Поворот экрана сохраняет текущий черновик.
- В журнале нажмите запись, чтобы прочитать полный текст и часовой пояс входа. Кнопка «Показать ещё» загружает следующую порцию истории.
- Настройки позволяют очистить журнал с подтверждением и перейти к системному управлению защитой.

## Ограничения

Защита рассчитана на официальный YouTube (`com.google.android.youtube`) в обычном полноэкранном режиме. Браузер, другие клиенты, YouTube Music, разделённый экран, дополнительные дисплеи и «картинка в картинке» не входят в поддерживаемый сценарий.

Android сообщает о смене приложения уже после его запуска: до вопроса возможны короткий показ YouTube и начало звука. Это инструмент самоконтроля; отключение сервиса или удаление приложения снимает защиту. Не все особенности прошивок производителей проверены.

Данные хранятся в приватном каталоге приложения, без сервера, интернета и аналитики. Облачное резервное копирование и перенос данных отключены. Сервис получает события смены окон и имена пакетов; доступ к содержимому чужих экранов не запрашивается. При удалении приложения журнал теряется.

## Сборка

Откройте проект в Android Studio с установленным SDK 37 и JDK, совместимым с Gradle 9.6 / AGP 9.4.1. Проект использует JDK из установленной Android Studio; путь к Android SDK задаётся в `local.properties`.

```bash
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest :app:lintDebug
```

Результат сборки: `app/build/outputs/apk/debug/app-debug.apk`. Копия для установки находится в `artifacts/YouTubeBlocker-debug.apk`. Это debug-сборка для личной установки; публикация в магазине и выпуск с постоянным ключом подписи не настроены.

## Устройство проекта

- `MainActivity.kt` — журнал, детали записи, настройки и инструкция подключения.
- `JournalViewModel.kt` — загрузка истории порциями и изменение настроек.
- `data/AppData.kt` — Room и DataStore. Схема версии 1 сохранена в `app/schemas`; при изменении схемы нужно добавить миграцию. Разрушительное пересоздание базы не используется.
- `protection/YouTubeGuardService.kt` — обнаружение YouTube и управление окном причины.
- `protection/GateOverlay.kt`, `ReasonScreen.kt` — окно с Compose-интерфейсом и клавиатурой.
- `protection/SessionGate.kt`, `ReasonRules.kt` — правила сеанса и Unicode-подсчёт длины.
